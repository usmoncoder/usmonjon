# usmonjon.site — lokal ishga tushirish

Talab: Node.js 20.11+ (`node -v` bilan tekshiring)

```bash
npm install
npm run dev
```

Brauzerda: http://localhost:3002  (ru: /ru, en: /en)

Production build tekshirish:

```bash
npm run build
npm start
```

Contact forma ishlashi uchun `.env.example` ni `.env.local` ga nusxalab,
Telegram bot token va chat id ni yozing.
